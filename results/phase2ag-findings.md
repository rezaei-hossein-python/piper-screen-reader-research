# Phase 2AG result

The corrected four-item blind set contained `F`, `S`, `A`, and `button`, each
with original, one-frame, and two-frame variants. The answer key was:

| Trial | A | B | C |
|---|---|---|---|
| 01 | C2 | C1 | Original |
| 02 | C1 | C2 | Original |
| 03 | Original | C2 | C1 |
| 04 | C1 | Original | C2 |

Thus Trial 04 B was the original Piper pronunciation. The user reported that
all variants preserved voice quality; Trial 04 B (original `button`) had the
best pronunciation. This validates that one- and two-frame separator/silence
edits can be perceptually safe, but does not establish that they improve
pronunciation or justify broader compression.
